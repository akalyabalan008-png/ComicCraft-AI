# Phase 7 – Project Documentation

## Project Title
ComicCraft – AI-Powered Comic Generator

## Project Overview

ComicCraft is a Generative AI-based web application that converts a simple story idea into a multi-panel comic.

The application uses AI to generate stories, scenes, dialogues, and comic panel images. The final comic can also be exported as a downloadable PDF.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- HTML/CSS
- Jinja2
- Google Gemini API
- Hugging Face Diffusers
- Stable Diffusion
- PyTorch
- Pillow
- FPDF
- Git and GitHub

## Major Features

- User-friendly comic generation interface
- AI-based story generation
- AI-generated comic scenes
- Dialogue generation
- Five-panel comic generation
- Comic preview
- PDF export

## System Modules

### 1. User Interface
Collects the required comic details from the user.

### 2. Story Generation
Uses Google Gemini to generate the comic story and scenes.

### 3. Image Generation
Uses Stable Diffusion to generate comic panel images.

### 4. Comic Layout
Arranges the generated images into a structured comic format.

### 5. PDF Export
Uses FPDF to create the final downloadable comic PDF.

## Project Development Result

The generated comic can be previewed and exported as a PDF.

## Limitations

- Output quality may vary depending on the generated content.

- Internet and API availability may affect AI-based features.
