# Phase 6 – Project Testing

## Project Title
ComicCraft – AI-Powered Comic Generator

## Testing Objective

The main objective of testing is to verify that all major features of ComicCraft work correctly and produce the expected output.

## Testing Approach

The application was tested by providing different user inputs and checking the generated story, comic panels, preview, and PDF output.

## Test Cases

| Test Case | Input / Action | Expected Result | Result |
|---|---|---|---|
| User Input | Enter character name, setting, tone, art style, and story prompt | Input should be accepted | Passed |
| Story Generation | Click Generate Comic | AI story and scenes should be generated | Passed |
| Image Generation | Generate comic panels | Five comic panels should be created | Passed |
| Dialogue | Check generated panels | Suitable dialogue should appear in panels | Passed |
| Comic Preview | Open generated comic | All five panels should be displayed | Passed |
| PDF Export | Click PDF download option | Comic PDF should be generated | Passed |
| PDF Content | Open generated PDF | Five comic panels should appear in the PDF | Passed |

## Functional Testing

The main functions tested were:

- User input handling
- AI story generation
- Comic panel generation
- Dialogue generation
- Comic preview
- PDF generation
- PDF download

All major functions produced the expected output during testing.

## Output Testing

The generated comic was tested using sample story details.

The application successfully generated five comic panels containing scenes and dialogues related to the given story.

The generated PDF was also opened and verified to contain the comic panels.

## Testing Result

The testing process confirmed that the major features of ComicCraft are working correctly.

The application successfully accepts user input, generates an AI-based comic, displays the generated panels, and exports the final comic as a PDF.
